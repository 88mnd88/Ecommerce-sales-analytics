# 📊 E-Commerce Sales Analytics & Customer Segmentation Dashboard (MS Excel / WPS Office)

## 📌 Project Overview
This pet project focuses on a comprehensive end-to-end data analysis of an e-commerce platform's operational performance. The dataset contains over 5,000 transaction records spanning from 2022 to 2026. 

The goal of the project was to clean raw transactional data, perform exploratory data analysis (EDA), engineer new business metrics, and build an interactive dashboard to uncover sales trends, geographical performance, and customer satisfaction issues.

---

## 💡 Key Business Insights (Executive Summary)
* **The Revenue Driver:** The *Electronics* category stands out as the primary revenue stream, contributing over 38% of total platform sales. 
* **The Quality Paradox (Critical Insight):** Over 53% of the total revenue in the *Home* category ($\$519,776.77$ out of $\$982,084.05$) is generated by products rated as **BAD** by customers. This indicates a severe product quality or logistics issue that poses a high churn risk.
* **The Demographic Shift:** In the *Home* segment, male customers consistently generate significantly higher revenue than female customers across all years. *Recommendation:* Reallocate marketing budgets to target male demographics for home improvement campaigns.
* **Geographical Hubs:** Sales are heavily concentrated in **Budapest** and **Milan**. Supply chain and warehouse scaling should be prioritized in these regional hubs.

## 🛠️ Technical Workflow & ETL (Extract, Transform, Load)

### 1. Data Cleaning & Anomalies Resolution
* **Date Format Harmonization:** Resolved a critical data corruption issue where dates were split into conflicting formats (`DD-MM-YYYY` and `MM-DD-YYYY`). Implemented nested string functions (`LEFT`, `MID`, `RIGHT`) paired with the `VALUE` function to standardize the entire timeline.
* **Synthetic Data Correction:** Identified and fixed a timeline anomaly where future transactions were logged up to the year 2035. Restructured the chronological sequence to simulate realistic, multi-order daily transactions.

### 2. Data Enrichment & Engineering
* **Relational Data Merging:** Used advanced lookup formulas (`VLOOKUP` / `INDEX+MATCH`) to seamlessly blend customer profile tables with the core transactions dataset.
* **Cohort Segmentation:** Formulated custom conditional boundaries to segment customers into automatic tier categories (`GOOD`, `OK`, `BAD`).
* **Financial Metric Engineering:** Calculated a standalone `Total Before Discount` metric to evaluate the financial leakage caused by promotional markdown campaigns.

### 3. Cross-Platform Dashboard Architecture (WPS Office Optimization)
* Built a dynamic analytical reporting layer utilizing multiple relational **Pivot Tables** and **Pivot Charts**.
* **Report Connections Bypass:** Overcame WPS Office's technical limitations regarding cross-cache Slicer isolation by implementing a custom **Cascade Filtering Architecture**. Slicers dynamically trigger a master table, which broadcasts parameters to isolated charts using `VLOOKUP` and `IFERROR` wrappers. This successfully locked chart color-coding (Red/Green UI) during active filtering.
